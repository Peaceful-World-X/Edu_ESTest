## 项目功能概览（精简）

- ESTest（STM32 控制器端）
  - 采集温湿度、温度、光照数据，并支持滤波开关。
  - 开机输出初始化/自检耗时，运行期输出控制耗时与 CPU 占用率。
  - 支持串口命令控制：`H/T/L/F=0/1`，可模拟传感器 error 与滤波开关。

- Python（测试端串口工具）
  - 9600 波特率实时接收并打印控制器串口消息。
  - 自动解析 `CPU:xx.xx%` 并实时绘制 CPU 波线图。
  - 可开启第二命令行窗口发送串口指令，支持与监控并行进行。
