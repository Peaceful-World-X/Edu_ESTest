# BUAA 嵌入式软件测试技术课程配套代码

## 项目简介

本项目为北京航空航天大学（BUAA）《嵌入式软件测试技术》课程的配套代码资源，旨在帮助学生更好地理解和掌握嵌入式软件开发与测试的相关知识与技能。

## 目录结构说明

- `ESTest_A1/` 嵌入式软件测试教学实验系统板-A1需求说明、演示代码、源文件等
- `Lec_class/` 理论课相关内容与配套代码
  - `Code_01_Hello/`  —— 在屏幕和串口中打印 "Hello tester" 的演示代码
  - `Code_02_Key/`    —— 在屏幕和串口中打印按下的按键数值的演示代码
  - `Code_03_UART/`   —— 实现通过串口进行简单通信的演示代码，输入 m+n，返回计算结果
- `Lab_class/` 实验课相关内容与实验安排
  - 实验2-半实物环境的单元级测试  ——  单元级测试场景（硬件在环/仿真）
  - 实验3-嵌入式软件系统测试实验  ——  系统级集成与功能验证
  - 实验4-三种滤波算法的对比实验  ——  滤波算法效果对比与评价

## 项目整体架构

项目从学习路径和知识能力培养两个维度组织：

1. 学习路径（Learning Path）

   - 理论讲解（`Lec_class`）→ 概念、接口、硬件抽象、测试点识别
   - 基础示例（`Code_01/02/03`）→ 串口/按键/显示等最小可验证单元
   - 实验设计（`Lab_class`）→ 将单点能力组合为可测试场景
   - 测试与验证（后续可扩展：自动化脚本、覆盖率、边界与异常场景）
2. 能力模块（Competency Modules）

   - 硬件交互：GPIO 输入（按键）、UART 通信、显示输出
   - 协议与数据：简单表达式解析（m+n），输入校验与异常处理（可扩展）
   - 测试用例设计：功能测试、等价类/边界值（例如按键值范围、m、n 的取值限制）
   - 可观测性（Observability）：串口输出、屏幕输出用于结果判定
   - 可复现性（Reproducibility）：每个示例最小依赖，便于重复验证

### 分层视角（Layered View）

| 层级       | 说明                           | 示例                 | 测试关注点                         |
| ---------- | ------------------------------ | -------------------- | ---------------------------------- |
| 硬件抽象层 | 底层外设接口（GPIO/UART/显示） | 按键读取、串口驱动   | 初始化是否成功；异常输入处理       |
| 设备功能层 | 将外设组合成基础功能           | 按键值显示；m+n 运算 | 功能正确性；边界值（如 0、最大值） |
| 交互协议层 | 人机/串口协议格式              | m+n 文本解析         | 输入格式鲁棒性，非法输入           |
| 测试支持层 | 输出与可观测性                 | 串口日志、屏幕输出   | 日志完整性、一致性                 |
| 学习引导层 | 文档与实验指引                 | README、实验说明     | 步骤清晰、可复现                   |

### 可扩展建议

- 为每个 Demo 增加：预期输入/输出表、异常/边界用例列表
- 增加统一的 `tests/`（可选 Python 脚本或主机侧串口交互脚本）做自动回归
- 在 UART Demo 中加入：非法格式（如 `m++n`、缺失操作数）处理逻辑示例
- 引入简单的覆盖率或用例跟踪表（手工阶段亦可）

### 学习路线建议

1. 搭建工具链并编译运行 `Code_01_Hello`
2. 调试按键采集：验证抖动现象与去抖策略（可扩展）
3. 串口表达式解析：实现输入校验与错误提示
4. 设计测试用例：列出正常/边界/异常三类集合
5. 编写主机侧脚本：批量发送输入并核对输出
6. 汇总：形成一次“需求→实现→测试→结论”的闭环报告

> 以上架构与建议有助于逐步引导：从会“跑起来”到“能验证”再到“系统性测试思维”构建。


## 开发环境与辅助工具

| 文件/工具                       | 作用             | 使用说明                                         |
| ------------------------------- | ---------------- | ------------------------------------------------ |
| `嵌入式开发环境配置指南.docx` | 环境配置指南     | 按文档安装编译器、驱动、调试工具链               |

### 建议的串口参数（若未特别说明）

```
波特率: 115200
数据位: 8
校验位: None
停止位: 1
流控: None
```

### 典型调试流程

1. 清理：执行 `keilkill.bat`（必要时）
2. 编译 & 下载：通过 Keil / 相关 IDE 烧录
3. 打开 `XCOM V3.0`，配置串口参数
4. 观察输出：确认启动 Banner + 数据刷新频率
5. 逐个测试：滤波切换 → 故障注入 → EEPROM 写入 → 断电重启读取
6. 记录：截取串口日志 + 采集若干周期数据做对比分析
